<!-- Introduction
This project contains seven JavaScript programming tasks designed to practise basic programming skills. The tasks cover decision-making, loops, arrays, pattern printing, and user input. Each task helps improve logical thinking and problem-solving skills.

Task 1: Grade Decision Engine 
This task involves creating a program that determines a student's letter grade based on their mark. The program uses if, else if, and else statements to assign grades from A to F, display feedback, and show whether the student passed or failed. It also rejects invalid marks below 0, above 100 or values that are not finite numbers.

Task 2: Weekly Class Planner 
This task uses a switch statement to convert a number from 1 to 7 into a day of the week. Tuesday, Thursday, and Saturday are CLASS days, while the remaining days are FREE TIME. The program uses default to handle invalid day numbers. The extra challenge is to print the complete weekly schedule using a loop.

Task 3: Loop Laboratory 
This task practises using different loops in JavaScript. A for loop prints even numbers from 2 to 50 in ascending order, while a while loop prints them in descending order. The continue statement is used to skip multiples of 6 when counting from 1 to 30. The extra challenge is to calculate the sum of odd numbers from 1 to 99.

Task 4: FizzBuzz with a Twist 
This task prints numbers from 1 to 100, replacing multiples of 3 with Fizz, multiples of 5 with Buzz, and multiples of both with FizzBuzz. It uses a loop and conditional statements to determine what to print. The program also counts the number of FizzBuzz outputs. The extra challenge extends the range to 150 and adds Pop for multiples of 7.

Task 5: Student Results Analyzer 
This task analyzes an array containing eight student marks: [78, 45, 92, 60, 33, 87, 50, 69]. A for...of loop is used to display each student's PASS or FAIL status and calculate the number of passes, failures, highest mark, lowest mark, total, and average. Array helper methods such as sort(), reduce(), filter(), Math.max(), and Math.min() must not be used. The extra challenge is to count the number of students in each grade category.

Task 6: Pattern Printing Studio 
This task uses nested loops to create six patterns with five rows: a growing right triangle, an inverted right triangle, a centered pyramid, an inverted pyramid, a number staircase, and a hollow square. Each row is built character by character. Spaces are used correctly to align the patterns. The extra challenge is to allow the row count to change.

Task 7: Five-Attempt Guessing Game
This task creates a browser-based guessing game with a fixed secret number, such as 37. The player has up to five valid attempts and receives feedback indicating whether each guess is too high, too low, or correct. The program uses break to stop when the correct number is guessed and reveals the secret number after five unsuccessful attempts. The extra challenge is to generate a random secret number between 1 and 100.

Technologies Used
The project uses JavaScript for programming, Node.js to run most tasks, and HTML with a web browser for the weekly class planner and the guessing game.

How to Run
Run JavaScript files using node filename.js in the terminal. For the weekly class planner and the guessing game, open the HTML file in a web browser and use the console. -->
